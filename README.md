# statistical-analysis-system
📊 Statistical Analysis System

A complete Python project that demonstrates descriptive and inferential statistics using a simulated student performance dataset.

This project covers almost the entire Statistics 101 syllabus in a single, well-structured program — including data visualization, probability, correlation, regression, sampling, and hypothesis testing.

🔍 Features

Automatic dataset generation

Frequency distributions

Data visualization (histogram, boxplot, pie chart, scatter plot)

Measures of central tendency

Measures of dispersion

Skewness and kurtosis

Correlation analysis

Linear regression

Probability calculations

Probability distributions (Normal, Binomial, Poisson)

Sampling & Central Limit Theorem

Hypothesis testing (t-test)

Mini case study with conclusions

🛠 Technologies Used

Python 3

NumPy

Pandas

Matplotlib

SciPy

▶️ How to Run
1. Install dependencies
pip install numpy pandas matplotlib scipy

2. Run the program
python statistical_analysis_system.py


The script will:

Print statistical results in the terminal

Display multiple plots for visualization

The dataset is synthetically generated and represents:

Attendance percentage (discrete)
